Round anatomy

The five hooks, in actual order

Composite subscribers run serially: app event lifecycle first, then recording, Homunculus, optional skills, optional active injection, optional timekeeper, and FooterController last. That final position lets same-hook producers queue a footer that becomes visible immediately.

before_round

Assemble this request

Refresh skills → inject active inbound → observe clock rollover → drain/dedup/render all footers as one system block. session_manager.py:421-450

after_generate

Make output canonical

Publish, record, append global block ids, store token boundary observations, accumulate detector input, update gas. homunculus.py:499-505

after_execute

Absorb consequences

Publish and record tool results, append ids, accumulate detector input, register large result TTLs. homunculus.py:507-510

between_rounds

Integrate at the boundary

Harvest Nursery → tick round TTLs → check planner → rerender if memory projection changed. homunculus.py:919-925

on_loop_exit

Close the loop

Harvest Nursery for every stop reason; tick end-turn TTLs only for literal end_turn. homunculus.py:927-930

session hooks

Frame the turn

Idle enter/exit, turn start/end, system response, and shutdown stay outside the round machine. session_lifecycle.py:15-40

Narrated traces

Three ways through the machine

Use the controls beneath the diagram for step-by-step highlighting. These prose versions remain searchable and printable.

A · A message arrives

  1. Runtime notes activity and enqueues a turn/injection.
  2. Idle selects the first eligible message and enters running.
  3. Turn start and inbound blocks become transcript truth.
  4. Homunculus assigns ids, accumulates detection, and renders active memory plus tail.
  5. Before-round producers run; FooterController injects one system footer block.
  6. Generate/execute records and integrates blocks; eligible tool results register TTLs.
  7. Between rounds harvests Nursery, ticks TTLs, checks Planner, and rerenders.
  8. Detection may schedule whenever an append crosses its interval.
  9. Loop exit harvests again; literal end_turn ticks end-turn TTLs; turn is closed.

B · The planner proposes compaction

  1. Generation input usage updates TokenMeter and GasGauge.
  2. Warning pressure selects the oldest ready full unpinned block.
  3. Proposal is recorded, reflected, and delivered as a footer.
  4. The entity may call Forget, with boundary and summary rechecks.
  5. At forced pressure Planner consumes the proposal itself.
  6. Apply-mode changes full to summary and invalidates render/count/gauge/proposal.
  7. The next generation observes the smaller context and shows the gauge drop.

C · A detection completes

  1. Fork completion marks a Nursery job ready; memory stays untouched.
  2. An explicit lifecycle boundary harvests it.
  3. Simulation sorts, bounds, closes tool pairs, and finds a contiguous safe prefix.
  4. Validation checks the semantic tiling and complete tool envelopes.
  5. Success records shutdown/detection/block birth and schedules metrics/summary.
  6. Each summary integration schedules the next oldest missing one.
  7. Failure leaves semantic state untouched and queues a courtesy footer; partial success lands only the safe prefix.

Future, deliberately bounded

Where Sleep may attach

These four dashed edges are design annotations, not implemented behavior. No Sleep edge is drawn from detector completion, summary completion, hearth, or arbitrary quantum completion.

future 1

Quiescent waking → dreaming

Manual Sleep is an entity action; waking and dreaming are sequential and mutually exclusive. Current quantum snapshotting independently requires no unfinished turn. memory-tree.md:83-111 · fork.py:508-535

future 2

Dreaming → apply frontier

The frontier already derives and plans without mutation. Slice 2 must execute through existing apply-mode records and report only transitions that landed. frontier.py:1-10, 294-465

future 3

Critical → forced Sleep

Forced Sleep attaches at a quiescent boundary and advances existing consented narratives only; it authors nothing at the hard limit. memory-tree.md:115-120 · frontier.py:650-658

future 4

Manifest → wake / idle

Every wake announces deltas, debts, and chapter-bearing dream transcript locations. Courtesy is part of the transition. frontier.py:477-595

Trace findings

⚠ Surprises

These are behaviors that were not obvious from the intended architecture. They are findings, not edits made by this documentation card.

01

Active injection is recorded but not integrated into Homunculus coordinates

InboundInjectionRoundLifecycle appends to the round and transcript, never to BlockManager. The next live generation reuses the omitted id; replay later includes the recorded injection. Live and canonical coordinates can drift. inbound.py:84-94 · homunculus.py:105-108, 499-510

02

dreaming exists only in the state types

Current runtime assignments enter suspended, idle, and running only. Slice 2 needs an actual entrance, exit, and failure contract. session_manager.py:58, 122-140

03

End-turn TTL means literal end_turn

Refusal, cancellation, max tokens, error, pause-turn, stop-sequence, and unspecified exits all close a manager turn but do not decrement end-turn TTLs. homunculus.py:927-930

04

Fatal exceptions bypass on_loop_exit

Retry exhaustion or a non-ToolError tool exception can escape before end_turn, leaving replay to identify an unfinished turn. loop.py:48-105 · rehydrator.py:290-315

05

A detector success may intentionally land only a prefix

Out-of-order completions can be deferred and later buffered ranges discarded while a contiguous prefix safely crystallizes. This degraded success is disclosed by footer. block_detector.py:165-190

06

Forget is also a summary scheduler

If its target summary is missing, Forget can queue that block immediately instead of waiting for the oldest-first cascade, then asks the entity to retry. block_manager.py:901-953

07

Bash timeout and background detach intentionally diverge

Timeout kills the process group. A shell already exited while a descendant holds stdout returns after drain grace and leaves the descendant running, with an incomplete-output note. filesystem.py:382-422, 469-514
