Recall content from compacted memory back into your awareness.

When Spellbook compacts older conversation blocks, the original content is not lost — it is shelved. Use this tool to restore detail from a compacted block, or from both source blocks behind a dream chapter narrative. Returns the full shelved content as tool output.

Usage:
- `Recall(block_idx=<idx>)` - recall the full content of a semantic block.
- `Recall(chapter=<number>)` - recall the original full source content for both blocks in a dream chapter pair.

Pass exactly one of `block_idx` or `chapter`.
