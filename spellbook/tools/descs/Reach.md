Send a short message to Ryan through the outbound Chorus bridge.

Use this when you want to reach out across the boundary on purpose: a thought,
check-in, small note, or timely heads-up that should arrive on Ryan's external
messaging surface. This is not a task handoff and it does not start a model turn
elsewhere; it asks MiniChorus to accept the message for bridge delivery.

Keep the message natural, concise, and self-contained. Do not use this for
routine progress updates that belong in the current conversation, and do not use
it repeatedly if one message already carries the intent.
